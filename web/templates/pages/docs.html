Quickstart

  1. Create an account and click the link in the verification email.
  2. Open API keys and create a key. Copy it: it is shown only once.
  3. Send a job and follow it:
{% call code("qs-curl", "shell") %}# 1. create a job from a YouTube video curl -s -X POST {{ base_url }}/api/v1/jobs/youtube \ -H "Authorization: Bearer $HC_API_KEY" -H "Content-Type: application/json" \ -d '{"url": "https://www.youtube.com/watch?v=VIDEO_ID"}' # 2. poll it (or pass "callback_url" and receive a webhook instead) curl -s {{ base_url }}/api/v1/jobs/JOB_ID -H "Authorization: Bearer $HC_API_KEY" # 3. download everything once status is "done" curl -L -o meeting.zip {{ base_url }}/api/v1/jobs/JOB_ID/bundle -H "Authorization: Bearer $HC_API_KEY"{% endcall %}

Authentication

Send your API key on every request, in either header:

{% call code("auth-headers", "http") %}Authorization: Bearer hc_live_AbCd1234_... # or X-API-Key: hc_live_AbCd1234_...{% endcall %}

Keys carry scopes. Give each automation only what it needs:

ScopeAllows
jobs:readList jobs, read their status, download outputs
jobs:writeCreate, render, cancel and delete jobs
zoom:readList the workspace's Zoom cloud recordings

Keys see only your own jobs. Revoke or rotate a key on the API keys page and it stops working immediately. For short scripts you can also log in with POST /api/v1/auth/login and send the returned access_token as a bearer token (it lasts 15 minutes).

{{ icon("alert") }}Keep keys out of source code and shared workflows: store them in your automation tool's credentials. A key in a public repository should be revoked at once.

Create a job

A job takes one recording from one of three sources. All three answer with the job (see Follow a job) and accept an optional callback_url for a webhook.

From Zoom

Use the meeting instance UUID from GET /api/v1/zoom/recordings or from Zoom's recording.completed event. Zoom's own transcript is reused. Sending the same meeting with the same options again returns the existing job with "deduplicated": true, so retries are safe. While Zoom is still processing, the answer is 425 with retry_after_s.

{% call code("jobs-zoom", "shell") %}curl -X POST {{ base_url }}/api/v1/jobs/zoom \ -H "Authorization: Bearer $HC_API_KEY" -H "Content-Type: application/json" \ -d '{"meeting_uuid": "Wb3kVw9xT8Wq1Z0rS5nYqg==", "options": {"shorts_count": 4}}'{% endcall %}

From YouTube

{% call code("jobs-youtube", "shell") %}curl -X POST {{ base_url }}/api/v1/jobs/youtube \ -H "Authorization: Bearer $HC_API_KEY" -H "Content-Type: application/json" \ -d '{"url": "https://www.youtube.com/watch?v=VIDEO_ID", "options": {"decide_only": true}}'{% endcall %}

Upload a file

Multipart form: file (.mp4, .mkv or .mov), optionally transcript (.vtt or .srt), title, callback_url, and any option as a form field.

{% call code("jobs-upload", "shell") %}curl -X POST {{ base_url }}/api/v1/jobs \ -H "Authorization: Bearer $HC_API_KEY" \ -F "file=@weekly-sync.mp4" -F "transcript=@weekly-sync.vtt" \ -F "title=Weekly sync" -F "shorts_count=2"{% endcall %}

Follow a job

GET /api/v1/jobs/{job_id} returns the job. Poll it every 15–60 seconds, or skip polling with a webhook. Useful fields: status, progress_current/progress_total (for stages with countable work), queue_position (0 = running), error_code, retryable, warnings, artifacts and links.

{% for status, text in statuses %}{% endfor %}
StatusMeaning
{{ status }}{{ text }}

List your jobs with GET /api/v1/jobs?limit=50&offset=0&status=active. Delete one with DELETE /api/v1/jobs/{job_id}; a running job needs ?force=true and is cancelled at its next checkpoint.

Outputs

GET /api/v1/jobs/{job_id}/bundle downloads bundle.zip with everything (resumable: Range requests are supported). Single files: GET /api/v1/jobs/{job_id}/artifacts/{name}, add ?download=true for an attachment.

FileContents
final.mp4The highlights reel, a title card, then the cleaned meeting
highlights.mp4The reel on its own
removed.mp4Every removed stretch of a second or more, labelled with source time and reason
shorts/short_NN.mp4 + .srtVertical 1080×1920 shorts with captions; shorts/shorts.json lists titles and source times
transcript_clean.txt/.jsonWhat is said in final.mp4, on its timeline
transcript_removed.txt/.jsonWhat was cut, with source times and reasons
chapters.txtYouTube chapter lines for final.mp4
report.pdfSummary, minutes removed by reason, highlights, shorts, chapters
manifest.jsonEvery file with its size, SHA-256, duration and status, plus warnings and timings

Optional outputs can fail on their own without failing the job: their status in artifacts says failed or skipped, with a reason, and warnings explains.

Webhooks

Pass callback_url when you create a job. When it finishes you get one POST:

{% call code("hook-payload", "http") %}POST /your/callback HTTP/1.1 Content-Type: application/json X-HC-Event: job.done # job.done | job.failed | job.decided | job.cancelled X-HC-Delivery: 3f9a... # unique per delivery X-HC-Signature: t=1790000000,v1=5f2c...e91a {"id": "3f9a...", "event": "job.done", "created_at": "2026-09-27T10:12:44Z", "job": {"job_id": "8c1d...", "status": "done", "title": "Weekly sync", "artifacts": {...}, "links": {"job": "{{ base_url }}/api/v1/jobs/8c1d...", "bundle": "{{ base_url }}/api/v1/jobs/8c1d.../bundle"}}}{% endcall %}

Verify the signature with your webhook secret (account page): HMAC-SHA256 over "<t>." + raw body, compared in constant time, and reject timestamps older than five minutes.

{% call code("hook-python", "python") %}import hashlib, hmac, time def verify(secret: str, raw_body: bytes, header: str) -> bool: fields = dict(part.split("=", 1) for part in header.split(",")) t = int(fields["t"]) if abs(time.time() - t) > 300: return False expected = hmac.new(secret.encode(), f"{t}.".encode() + raw_body, hashlib.sha256).hexdigest() return hmac.compare_digest(expected, fields.get("v1", "")){% endcall %} {% call code("hook-node", "javascript") %}import crypto from "node:crypto"; export function verify(secret, rawBody, header) { const f = Object.fromEntries(header.split(",").map((p) => p.split("="))); if (Math.abs(Date.now() / 1000 - Number(f.t)) > 300) return false; const expected = crypto.createHmac("sha256", secret).update(`${f.t}.`).update(rawBody).digest("hex"); return f.v1?.length === expected.length && crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(f.v1)); }{% endcall %}

Retries: anything but a 2xx answer (or no answer within 10 seconds) is retried after 1, 5 and 30 minutes, then given up. Each job page lists its deliveries. Answer quickly and do the work afterwards; use X-HC-Delivery to ignore duplicates.

Rules for the URL: https://, reachable on a public address, no redirects. Test yours from the account page, or with POST /api/v1/webhooks/test, which sends a signed ping.

n8n, Zapier and Make

n8n: cut every new Zoom recording

  1. Trigger: a Webhook node subscribed to Zoom's recording.completed event (or a Schedule node).
  2. HTTP Request node: method POST, URL {{ base_url }}/api/v1/jobs/zoom, authentication "Header Auth" with name Authorization and value Bearer hc_live_..., JSON body {"meeting_uuid": "{{ '{{' }} $json.payload.object.uuid {{ '}}' }}", "callback_url": "<your n8n webhook URL>"}. Enable "Retry on fail"; a 425 means Zoom isn't ready yet.
  3. Second workflow: a Webhook node at that callback URL receives job.done; an HTTP Request node downloads {{ '{{' }} $json.body.job.links.bundle {{ '}}' }} with the same header, as a file.

Zapier

  1. Action Webhooks by Zapier → POST to {{ base_url }}/api/v1/jobs/youtube with the header Authorization: Bearer hc_live_... and data url. Add callback_url pointing at a Catch Hook trigger of a second Zap.
  2. The second Zap receives job.done and can post job.links.app to Slack or email.

Make

  1. An HTTP → Make a request module: POST, JSON body, header Authorization. Parse the response to keep job_id.
  2. A Webhooks → Custom webhook scenario receives the finished event.

A 20-line Python client

{% call code("client-python", "python") %}import os, time, httpx api = httpx.Client(base_url="{{ base_url }}/api/v1", timeout=60, headers={"Authorization": f"Bearer {os.environ['HC_API_KEY']}"}) def cut(youtube_url: str, out: str = "meeting.zip") -> dict: job = api.post("/jobs/youtube", json={"url": youtube_url}).raise_for_status().json() while job["status"] not in ("done", "failed", "cancelled", "skipped_desync"): time.sleep(30) job = api.get(f"/jobs/{job['job_id']}").raise_for_status().json() if job["status"] != "done": raise RuntimeError(f"{job['error_code']}: {job['error']}") with api.stream("GET", f"/jobs/{job['job_id']}/bundle") as r, open(out, "wb") as f: for chunk in r.iter_bytes(): f.write(chunk) return job{% endcall %}

Limits

  • API keys: 120 requests per minute per key; signed-in browsers 600 per minute. Over the limit: 429 rate_limited.
  • Queue: one job renders at a time; each account can have {{ limits.max_queued_per_user or "several" }} jobs waiting or running (429 too_many_jobs). When the whole queue is full: 503 busy.
  • Plan: {% if limits.jobs_per_month %}{{ limits.jobs_per_month }} jobs a month{% else %}no monthly job limit{% endif %}{% if limits.max_minutes %}, recordings up to {{ limits.max_minutes }} minutes{% endif %} (402 plan_limit).
  • API keys per account: {{ limits.max_api_keys }}.

Self-hosting

The product is one Docker image plus Caddy for automatic HTTPS. On a small Linux server:

{% call code("selfhost", "shell") %}git clone <your fork> highlight-cutter && cd highlight-cutter cp .env.example .env # set APP_ENV=prod, APP_BASE_URL, JWT_SECRET, EMAIL_*, the AI key, Zoom DOMAIN=cut.example.com docker compose up -d docker compose exec app python -m db.cli create-admin you@example.com{% endcall %}

The repository's DEPLOY.md covers DNS, email (SPF and DKIM), backups, upgrades and sizing.
