{# ---------------------------------------------------------------- how it works #}

The transcript is the edit.

No timeline and no scrubbing. An AI editor marks up every sentence the way a copy editor would, and ffmpeg cuts exactly what it marked.

  1. Bring a recording

    A YouTube link or a file from any meeting tool. Captions, or a .vtt or .srt you already have, are reused.

  2. An AI editor marks it up

    Each sentence is kept or cut, with a reason. You can say in plain words what counts as a highlight.

  3. ffmpeg cuts exactly that

    Cuts land on the source frame grid, kept parts meet with a short dissolve, and long silences shrink to a beat.

# Cut a YouTube video and get a webhook when it's done
curl -X POST {{ base_url }}/api/v1/jobs/youtube \
  -H "Authorization: Bearer $HC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.youtube.com/watch?v=VIDEO_ID",
    "options": { "shorts_count": 4 },
    "callback_url": "https://n8n.example.com/webhook/cut"
  }'
import os, time, httpx
api = httpx.Client(base_url="{{ base_url }}/api/v1",
                   headers={"Authorization": f"Bearer {os.environ['HC_API_KEY']}"})
job = api.post("/jobs/youtube", json={"url": "https://youtu.be/..."}).json()
while job["status"] not in ("done", "failed"):
    time.sleep(30)
    job = api.get(f"/jobs/{job['job_id']}").json()
open("meeting.zip", "wb").write(api.get(f"/jobs/{job['job_id']}/bundle").content)
